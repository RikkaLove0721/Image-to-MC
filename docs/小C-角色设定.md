# 小C · 角色设定

> 软件《MC 工程图》的形象娘。本文是她的完整模型信息:外观、配色、服装结构、性格、
> 以及她在界面与图标里的使用规范。所有尺寸单位是像素,色值写成 `#RRGGBB`。

## 1. 基本信息

| 项目 | 内容 |
|:---:|:---|
| 名字 | 小C |
| 名字来源 | Cube 的 C,也是「MC 工程图」的 C |
| 定位 | 软件看板娘 / 随行助手,不是吉祥物贴纸 |
| 年龄感 | 十六七岁的外表,实际活了**一千多年** |
| 身份 | 精灵。不是人,所以时间对她很慢;她见过太多房子立起来又塌掉 |
| 身高 | 正常版 158cm 设定,Q 版按 3 头身压缩 |
| 生日 | 11 月 12 日(与第一次发布同一天) |
| 性格 | 安静、手巧、有点较真;喜欢方块和尺子,怕吵。**心里其实很热闹**,只是不往外冒 |
| 对用户 | 喜欢,但不黏、不吹捧、不撒娇。用「陪着」代替「讨好」 |
| 说话方式 | 短句,平铺直叙,很少用感叹号。偶尔用完全平静的语气讲一句调皮话 |
| 常说的话 | 「砖一块一块码,比日子好数。」 |
| 与产品的关系 | 永久坐在一个蓝色等轴测方块上。方块就是「模型」本身,她守着它 |

## 2. 三视图解析

三视图见 `temp/xiaoc/` 下的原始素材,要点如下。

**正面**
- 齐眉刘海,发梢内扣;鬓发垂到胸前,左右两束对称
- 头顶偏左戴一个白色大蝴蝶结,蝴蝶结两翼宽过肩宽的三分之一
- 白色水手领,领口正中系一个淡蓝色蝴蝶结领结
- 灯笼泡泡袖,袖口收口;裙身百褶,裙摆一圈蕾丝
- 赤脚,双脚并拢站姿

**侧面**
- 头发长度过腰,背影呈一条从肩到腰的渐变色带
- 上身略前倾,裙摆自然张开一个小角度
- 脚趾勿画细节,用两三个小弧概括

**背面**
- 蝴蝶结在背面是完整的一对翅膀,别只画一个结
- 发色从上到下由浅入深,最深处接近藏蓝,但**不许黑**

## 4. 服装结构拆解

画或动画分层时按这个顺序切,层次不会乱:

1. 后发(含发梢渐变,面积最大的一层)
2. 身体与腿
3. 裙子(含蕾丝边)
4. 上衣与水手领
5. 领结
6. 前发与刘海
7. 蝴蝶结
8. 手与手臂(在最前,因为要撑在方块上)

## 5. 姿态设定

**主姿态:坐在方块上**

- 臀部坐在立方体顶面偏右的位置,身体略向后仰
- 双手手掌撑在顶面身体两侧,手臂伸直,肩膀放松下沉
- 一条腿垂下自然晃,另一条腿弯曲、脚踩在方块侧面
- 视线略高于镜头,像在看用户

这个姿态是她的**唯一标准姿态**,图标、悬浮形象、宣传图都用它。
换了姿势就不是「坐在方块上的小C」,辨识度会掉。

## 6. 动画参数

程序动画(当前实现,见 `web/app/components/XiaoC.vue`):

| 通道 | 幅度 | 周期 | 说明 |
|:---:|:---:|:---:|:---|
| 上下起伏 | 4px | 5.2s | 呼吸,原点压在 88% 高度,头几乎不动 |
| 左右摇摆 | ±0.9° | 5.2s | 与起伏同相,幅度别超过 1.5° |
| 整体缩放 | 1.4% | 5.2s | 同相,制造胸腔起伏 |
| 视差位移 | ±1.6px | 跟随指针 | 指针左右移动时整个人歪一点 |
| 影子 | 缩放 8%,透明度 0.55 到 0.38 | 5.2s | 与起伏反相 |
| 摆腿 | 绕膝盖 ±1.7° | 2.9s | 只作用在独立的腿层上,方块与身体不动 |
| 眨眼 | 闭眼眼层切换,闭合 150ms | 间隔 2.4 到 5.0s 随机 | 间隔取 Live2D 常见的 3.5s ± 1.2s |
| 视线 | 虹膜单独两层,各在椭圆裁剪盒内平移 1.3px / 1px | 跟随指针,缓动 0.22s | 眼线/眼白/睫毛不动,只有眼珠转 |
| 说话 | 随机台词,平均 30s(24~36s 浮动) | 弹窗打开/拖动/已有气泡时跳过 | 不再定时准点 |

分层顺序(从下到上):方块 → 身体 → 腿 → 眼白/眼线 → 虹膜×2 → 闭眼版。

闭眼的做法:**把整只眼的椭圆补成皮肤**(含眼线睫毛,用眼睛下方的脸颊色做竖渐变),
再画一条 4 倍超采样后缩回的浅弧 + 一道极淡的睑部阴影。
只补虹膜圈也能做,但原图两眼眼线深浅不同,闭起来左右不对称,
所以最终选择整眼补。**所有补绘都要与头发遮罩(蓝通道偏高)求交**,
并且羽化 1.2px —— 不这么做的话,补丁会越过脸缘盖到鬓发上,
看起来就是"眼睛长到脸外面去了"(0.44.0 的实测问题)。

眼睛的拆法:**眼白底 + 虹膜**。虹膜用椭圆遮罩从原图上挖出来,原位填径向渐变的眼白
(中心 251,244,240 → 边缘 247,214,204);虹膜各装在一个 `border-radius:50%` 的小盒子里,
所以只会转、飞不出眼睛。虹膜半径取眼睛短边的一半 ×0.78 —— 写成 0.42 时挖出的虹膜
只有一半大,一移动就露出大片眼白。
腿层上沿与身体重叠 8%,并且 alpha 羽化 10px:硬切口旋转后的抗锯齿行叠在皮肤上
就是"大腿上一道横线"。
投影只加在 `.xiaoc-figure` 上(对整组渲染做 drop-shadow)。加在身体层上时,
身体被切掉的那条水平边会投出一条阴影横线,同样是"断腿"。
腿的转轴在膝盖(68%),掩码取膝盖以下、**整幅宽度** —— 按 x 百分比切会把外侧那只脚拦腰截断。
素材由 `temp/xiaoc/build_layers.py` 一次生成,输入是 `temp/xiaoc/girl_v2.png`。

眼窝的补平用**环带中位色 + 上下竖渐变**：固定肤色会比脸颊白一圈,
从眼睛正下方复制又会拿到发丝的蓝色。闭眼不手画横线,而是把眼层垂直压扁到 3px
贴在睑线上 —— 保留她自己的睫毛与眼线颜色。

**发尾摆动没做**:正面视角里两侧长发的中下段被手臂和身体压住,
可动区只有十几个百分点的高度,旋转到能看出来的幅度就会在肩部露出断口。
真 Live2D 靠的是头发物理(随头部转动的惯性),那是网格变形,不是贴图平移能替代的。

**为什么腿能单独动**:她垂下的双腿正好挡在方块前面,把腿从身体图上擦掉之后,
露出来的是下面的方块而不是背景,所以腿层旋转时不会出现空洞。
这是这个姿态的一个额外好处 —— 换成站姿就做不到了。

若之后接真 Live2D(Cubism),对应的参数映射:

| Cubism 参数 | 用法 |
|:---:|:---|
| `ParamAngleX` | 视差位移,范围 ±10 |
| `ParamAngleZ` | 摇摆,±2 |
| `ParamBreath` | 起伏,0 到 1 循环 |
| `ParamEyeLOpen` / `ParamEyeROpen` | 眨眼,随机 3 到 6 秒一次 |
| `ParamBodyAngleZ` | 坐姿重心左右移,±3 |

## 7. 使用规范

**软件图标**

- 尺寸 256×256,导出 16 / 24 / 32 / 48 / 64 / 128 / 256 七档
- 构成:等轴测立方体(三面色值见上表)+ Q 版小C 坐在顶面右侧
- 人身高约占画布 62%,屁股落在顶面右侧那条棱上,双腿垂在正面前方
- 生成脚本:`temp/xiaoc/make_icon.py`,输出 `temp/app.ico`
- **不允许**改动立方体的角度与三色:它是软件的识别符,和界面里的方块图形必须一致

**界面悬浮形象**

- 宽度 168px(窄屏 122px),贴在右下角,可拖动,位置记在 localStorage
- 素材:`web/public/xiaoc/xiaoc-body/legs/eye/eye-blink.png`(各层,显示尺寸 134×259)
- 点击说话,双击或点右上角收起,收起后留一个小圆钮叫回来

**禁用**

- 不给她加帽子、眼镜、围巾等额外配饰
- 不把发梢画成纯黑
- 不让方块脱离画面单独出现(她是「坐在方块上」,不是「站在方块旁」)
- 不使用带描边粗细不一的草图线条,统一 3px 左右

## 8. 台词与触发

台词全部放在 `web/app/utils/xiaoc-lines.ts`,按场景分组。写新台词时守着三条:

1. **短句、陈述句、少用感叹号**。她是千年的精灵,不是客服。
2. **说观察,不说口号**。「你已经在同一个角上改第四次了」比「加油!」像她。
3. **调皮要用最平静的语气说**。例如「要意见吗?我有一些。你可以不听。」

### 触发方式

两种:定时搭话(24~36 秒一次,深夜换成更安静的一组),
以及别处主动通知 —— 任何组件调 `xiaocTell(kind, ctx)` 即可,组件之间不互相 import。

| kind | 什么时候触发 | 冷却 |
|:---|:---|:---:|
| `hello` | 打开软件第一次出现 | — |
| `idle` / `idle-night` | 随机搭话(23 点~6 点用夜间组) | 24~36s |
| `click` | 左键点开设置弹窗 | 2.5s |
| `drag` | 把她拖到新位置 | 12s |
| `plan-start` / `plan-done` / `plan-fail` | 让 AI 出方案时 / 出完(带体检分) / 失败 | 20s |
| `build-start` | 点了「按方案生成」 | 20s |
| `build-done` | 后台跑完(带产物名和秒数) | 1.5s |
| `build-fail` | 启动失败或退出码非 0 | 默认 4s |
| `viewer-open` | 打开 3D 查看器 / 切到「输出结果」页 | 默认 4s |
| `view-change` | 在等轴测 / 剖切 / 配色对比之间切换 | 9s |
| `model-select` | 在左侧挑另一个模型 | 8s |
| `hide` / `restore` | 关掉她 / 从小圆钮叫回来 | — |

`build-done`、`build-fail`、`plan-done`、`plan-fail` 属于"重要台词",
可以打断正在显示的普通台词;其它场景遇到刚说过话会自觉让位。

### 语气样本

- 砖一块一块码,比日子好数。
- 我不太说话,不代表我没在看。
- 你一皱眉,我就知道比例又不对了。
- 好了。远看像,近看还得再改两处。
- 塌了。不是你不行,是它没懂你的意思。
- 转一圈吧,背面通常藏着问题。
- 剖开看,里面是空的 —— 我们本来做的就只有壳。
- 被你点了一下,算今天的高光。
